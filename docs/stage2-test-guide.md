# 2단계 실기기 검수 안내 — 잠긴 휴대폰에서 자동 말걸기

대상 빌드: `영어자동말걸기` 0.2.2-stage2 (versionCode 3, 디버그 서명) · 기기: Galaxy S24 Ultra / One UI 8.5 / Android 16

**2단계 통과 기준:** 화면이 꺼지고 잠긴 휴대폰에서 지정 시각에 화면이 저절로 켜지고, 첫 영어 문장이 소리로 나온다.
이 기준을 통과하기 전에는 3단계(AI 대화 연결)로 넘어가지 않는다.

## 1. 설치
1. 전달받은 `EnglishAutoTalk-0.2.0-stage2.apk`를 휴대폰으로 옮긴다(카카오톡 나에게 보내기, 구글 드라이브, USB 등).
2. 내 파일 앱에서 APK를 누른다 → "출처를 알 수 없는 앱" 경고가 나오면 **설정** → 해당 앱(내 파일/Chrome 등)의 **이 출처 허용** 켜기 → 뒤로 가서 **설치**.
3. Play 프로텍트가 "앱을 검사하지 않았습니다"를 띄우면 **세부정보 → 무시하고 설치**.

## 2. 첫 실행 설정 (홈 화면의 '자동 시작에 필요한 설정')
모든 줄이 ✅가 될 때까지 진행한다. ⚠️ 줄의 **설정** 버튼을 누르면 해당 화면으로 간다.

| 항목 | 누를 곳 |
| --- | --- |
| 알림, 마이크 | **알림·마이크 권한 한 번에 허용** → 허용 / 앱 사용 중에만 허용 |
| 전체화면 알림 | 설정 → 영어자동말걸기 스위치 켜기 (Android 14+에서 꺼져 있을 수 있음) |
| 정확한 시각 알람 | 보통 이미 ✅. ⚠️면 설정에서 허용 |
| 배터리 최적화 제외 | 팝업에서 **허용** |
| 삼성 절전 예외 | 휴대폰 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱** → + → 영어자동말걸기 |

추가 확인: 설정 → 접근성/일반 → **텍스트 읽어주기(TTS)** 에서 영어(미국) 음성이 설치돼 있는지. 미디어 볼륨이 0이 아닌지.

## 3. 테스트 시나리오 (결과를 표로 알려 주세요)

| # | 조작 | 기대 결과 |
| --- | --- | --- |
| T1 | 홈에서 **지금 바로 말걸기 화면 열기** | 영어 인사+주제 질문이 소리와 자막으로 나오고, "듣는 중" 표시 후 영어로 말하면 인식 문장이 나오고 짧게 대답한 뒤 닫힘 |
| T2 | **1분 뒤 말걸기 테스트** → 전원 버튼으로 화면 끄기 → 1분 대기 | **잠금 해제 없이** 화면이 켜지고 대화 화면이 뜨며 첫 문장이 소리로 나옴 (**2단계 핵심**) |
| T3 | T2와 같이 하되 이어폰(버즈 등) 연결 | 음성이 이어폰으로 나옴 |
| T4 | T2에서 대답하지 않기 | 약 8초 뒤 "Are you there?…" 1회 → 다시 8초 무응답 → 작별 인사 후 닫힘 |
| T5 | 매너(진동)/무음 모드로 바꾸고 T2 | 화면이 켜지지 않음. 기록에 "무음/매너 모드 — 말걸기 건너뜀" |
| T6 | 방해금지 켜고 T2 | 소리 없이 화면+진동, "터치하면 시작". 터치하면 음성 시작 / 30초 무반응이면 닫힘 |
| T7 | 대화 화면에서 **패스** | 즉시 닫힘. (테스트 예약은 재시도하지 않음 — 매일 일정에서만 1시간 뒤 재시도) |
| T8 | 휴대폰 재부팅 후 앱 열기 | 기록에 "예약 복원 (재부팅)", '다음 말걸기' 시각이 유지됨 |
| T9 | 다음 날 실제 14:00 | 화면 꺼짐·잠금 상태에서 자동으로 말걸기 시작. 홈의 기록에서 '예약 vs 지연 초' 확인 |

각 항목마다 알려 줄 것: 통과/실패, 홈 화면 **기록**에 찍힌 줄(스크린샷이면 충분), 특이사항.

## 4. 이 빌드의 한계 (2단계 범위)
- 대답을 한 번 들으면 고정 문장으로 답하고 끝난다. 실제 AI 대화·교정 요약·기록 저장은 3단계.
- 휴대폰을 사용 중(화면 켜짐·잠금 해제)일 때는 Android 정책상 전체화면 대신 **상단 알림**으로 뜬다. 알림을 누르면 시작.
- 강제 중지(설정 → 앱 → 강제 중지)하면 예약이 사라진다. 앱을 다시 열면 복구된다.
- 방해금지 설정에서 '전체화면 알림 차단' 옵션을 켜 두면 T6에서 화면이 켜지지 않을 수 있다 [실기기 확인 필요].

## 5. 0.2.1 추가 — 음성 명령 테스트

| # | 조작 | 기대 결과 |
| --- | --- | --- |
| V1 | 첫 문장 뒤 "I'd like to talk about travel." 하고 잠시 쉬었다가 "Because I love trips. Over to you." | 쉬는 동안 끊기지 않고 계속 들음. "Over to you"에서 두 문장이 한 대답으로 합쳐져 표시되고("Over to you"는 빠짐) 앱이 답함 |
| V2 | 대답 뒤 "I'm all set" | V1과 같이 대답이 끝남 |
| V3 | "Help me in Korean" | 한국어 음성으로 도움 + 화면에 예문, 이어서 "Okay, now try it in English" 후 다시 들음 |
| V4 | 한국어로 "잘 모르겠어요" | V3과 같음 (인식기가 한국어 감지를 지원할 때만 — 안 되면 알려 주세요) |
| V5 | 말을 시작한 뒤 끝 신호 없이 20초 이상 조용히 | 대답하지 않고 계속 듣다가, "Over to you"를 말하면 그때 대답함. 듣는 동안 비프음이 나지 않음 |

한국어 음성이 안 나오면: 설정 → 일반 → 텍스트 읽어주기 → 기본 엔진의 언어에 한국어 설치 여부 확인.
