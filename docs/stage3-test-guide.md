# 3단계 실기기 검수 안내 — AI 영어 대화 한 회차

대상 빌드: `영어자동말걸기` **0.3.0-stage3** (versionCode 4, 디버그 서명). 기존 앱 위에 덮어 설치하면 되고, 일정과 권한은 유지된다.

**3단계 통과 기준:** 지정 시각(테스트는 1분 뒤)에 앱이 먼저 말을 건다 → 말로만 대답한다 → AI와 5분 또는 8왕복 대화한다 → 마무리 → 교정 3개가 표시된다 → 홈 화면 '대화 기록'에 저장된다.

## 1. 처음 한 번: AI 설정 (홈 화면 'AI 대화 설정' 카드)
1. aistudio.google.com → **Get API key**에서 기존 키를 복사한다. **이 대화창이나 다른 곳에는 붙이지 않는다.**
2. 앱의 **Gemini API 키 붙여넣기** 칸에 붙이고 **키 저장**을 누른다. "저장됨 (…마지막 4자리)"로 바뀌는지 확인한다.
3. 모델은 기본 `gemini-3.5-flash-lite`로 둔다.
4. **연결 테스트**를 누른다.
   - ✅ 연결 성공 → 다음 단계로
   - ⚠️ 404 → 모델을 `gemini-3.1-flash-lite`로 바꿔 다시 테스트
   - ⚠️ 403 → 키를 확인한다
   - 결과 문구를 그대로 알려 주면 된다.
5. 키를 넣지 않으면 **기본 연습(AI 아님)**으로 진행된다. 화면 위에 빨간 띠로 표시된다.

## 2. 테스트 시나리오

| # | 조작 | 기대 결과 |
| --- | --- | --- |
| A1 | **지금 바로 말걸기 화면 열기** → 주제를 고르고 대답할 때마다 끝에 "Over to you" | Mia가 짧게 대답하며 질문 1개로 이어간다. 뜻이 안 통할 만큼 심한 오류만 "You can say: …"로 즉시 고쳐 주고, 작은 실수는 지적하지 않는다(끝난 뒤 교정 화면에 나옴) |
| A2 | A1을 8번 대답하거나 5분 넘게 | 마무리 인사 → "내 영어 교정 중…" → **오늘의 영어 교정** 화면: 내 문장 전체(내가 한 말 / 고친 문장 / 더 자연스럽게 / 한국어 설명, 틀린 곳 없으면 ✓) + 꼭 기억할 교정 3개 → 닫기 |
| A3 | 대화 중 "Help me in Korean" | 한국어 2문장 이내 도움 + 영어 예문 → 다시 영어로 유도 |

| A5 | 비행기 모드로 A1 | 오프닝은 그대로 나오고, 첫 대답 뒤 빨간 띠 "기본 연습 — AI 응답이 아닙니다 (인터넷에 연결할 수 없어요)" + 고정 질문으로 계속. 대답은 기록에 저장 |
| A6 | 설정에서 키 삭제 후 A1 | 처음부터 기본 연습 띠 표시(API 키가 없어요) |
| A7 | **1분 뒤 말걸기 테스트** → 화면 끄기 | 잠긴 상태에서 화면이 켜지고 → 말하기 → 대화 → 요약까지 조작 없이 말로만 완료 (**2단계 T2 + 3단계 핵심**) |
| A8 | 대화 3번 한 뒤 **패스** | 말한 3문장 교정 화면이 뜬 뒤 종료, 기록에 "패스"로 저장. 완료 기준(5분/8왕복) 전이므로 매일 일정에서는 1시간 뒤 재시도 |
| A9 | 홈 → 대화 기록 → 전체 삭제 → 확인 | 기록이 모두 사라짐 |

알려 줄 것: 각 항목 통과/실패, 연결 테스트 결과 문구, Mia 응답이 너무 길거나 어려웠던 예, 교정 3개 화면 스크린샷.

## 3. 알려진 제약
- Mia 응답 품질과 무료 한도는 **실제 키로 처음 확인**하는 것이다. 이 빌드를 만든 환경에는 키가 없어 실제 Gemini 호출을 시험하지 못했다.
- 무료 Gemini는 대화 내용을 Google 제품 개선에 쓸 수 있다(사용자 동의함). 개인정보·회사 기밀은 말하지 않는다.
- 응답을 기다리는 동안 "생각 중…"이 1~3초 정도 보일 수 있다.
- 기본 연습 모드(키 없음·오류)에서는 회차 종료 시 교정을 만들지 않는다. 대신 키를 넣은 뒤 홈 → 대화 기록 → **교정 받기**로 그 회차의 교정을 받을 수 있다.
